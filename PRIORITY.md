# Status (2026-09-07)

All-n `O(√n)` is proved: `sat_3(n) < 2√n` (Theorem 9.2 / `sat3_O_sqrt`).
The former gap after `M_k` for base-4 tiling was real for that tiling; variable admissible digits close it.

Csajbók–Nagy [2] already have `a(3-AP, Z_m) < 2√m` via R-complete sets and a modular window `2R < m ≤ 3R+1`. This paper is the interval `[n]`: longer placement window `R+1 ≤ n ≤ 3R+1`, no wrap-around, exact table, Lean spine.

Do not advertise "first O(√n) for intervals". Novelty is `sat_3` on `[n]`, placement, and the table, not the digits.
